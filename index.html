htmx contribution demos

Side-by-side before/after demos for bug fixes contributed to bigskysoftware/htmx. Each demo loads two builds of htmx from the same base commit, differing only by the proposed patch.

Fix: hx-download prefers ASCII filename= over UTF-8 filename* PR open #4020
Dual Content-Disposition headers made parseFilename() take the first filename= token and ignore RFC 5987 filename*.

Fix: hidden-document view transition unhandledrejection PR open #3989
startViewTransition().ready rejects when the document is hidden. Catching only .finished leaked an unhandled InvalidStateError.
Base: 7f9160f0 · PR #4044 · Open demo →
Fix: timeout abort reason is TimeoutError PR open #4021
Timeouts called abort() with no reason, so they were indistinguishable from hx-sync replace. Pass TimeoutError.
Base: 7f9160f0 · PR #4045 · Open demo →
Fix: hx-swap-oob="textContent" falls back to defaultSwapStyle PR open #3563
swapWithStyle() has no case for textContent, so OOB textContent swaps fall through to innerHTML and parse markup as HTML instead of inserting it as literal text.
Base: d53932d4 · 3-line fix in src/htmx.js · Open demo →

Three call sites used raw classList.remove() instead of htmx's existing removeClassFromElement(), leaving an empty class="" attribute on elements that had no classes before the htmx operation.
